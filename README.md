проект симулятор пульта сгу дпс машины
короче тут 4 кнопки крякалка основная сирена быстрая и двойная
сделано на html css и web audio api чтоб звуки не лагали и накладывались друг на друга

как запустить:
скачиваешь файлы запускаешь локальный сервер типа python -m http.server или live server в вскоде и открываешь index.html в браузере
если просто файл открыть то браузер может заблокировать загрузку звуков через fetch

на телефоне если два раза тапнуть по пустому месту то будет на весь экран
