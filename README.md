# PolicySGU

Минималистичная звуковая панель на HTML, CSS и Web Audio API.

В интерфейсе остались только кнопки звуков и стилизованный регулятор громкости:

- начальная громкость — 100%;
- диапазон — от 1% до 500%;
- секретные сигналы плавно затухают за 200 мс;
- микрофон передаёт чистый сигнал без эффектов и записи;
- общий выход защищён от грубого цифрового клиппинга;
- звуки предварительно загружаются и могут накладываться друг на друга.

## Запуск

Запустите локальный сервер в папке проекта:

```bash
python -m http.server
```

Затем откройте `http://localhost:8000`.
