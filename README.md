# PolicySGU

Интерактивная звуковая панель и саундпад на HTML, CSS и Web Audio API.

Звуки разложены по категориям:

- `sounds/DPS` — сигналы ДПС (крякалка, сирены, голосовые команды, микрофон);
- `sounds/Mems` — мемы (Коч, Братан, Голда, Тебе, Пантера, Мусор дроп);
- `sounds/Gudok` — автомобильные, железнодорожные и корабельные гудки.

Категории переключаются горизонтальным свайпом, колёсиком мыши или клавишами `←` / `→` (или `A` / `D`).

## Особенности и управление

- **Режим саундпада (MPC / Sampler):** мгновенный отклик, статтер-нарезка и полифония без задержек.
- **Двухуровневая кнопка «Мусор дроп»:**
  - *Быстрый клик/тап:* короткий акцентированный дроп-удар;
  - *Зажатие (Hold):* воспроизведение полной версии фразы с золотым свечением и финальным эффектом взрыва.
- **Мультитач:** поддержка одновременного нажатия нескольких пэдов на сенсорных экранах.
- **Горячие клавиши (ПК):**
  - `1` ... `6` — запуск соответствующих пэдов текущей категории;
  - `Space` (Пробел) — в мемах управляет дропом (тап — короткий, удержание — полный трек);
  - `←` / `→` или `A` / `D` — переключение экранов.
- **Диапазон громкости:** от 1% до 500% с защитой от клиппинга через `DynamicsCompressorNode`.
- **Микрофон:** Push-to-Talk прямая передача сигнала.

## Запуск

Запустите локальный сервер в папке проекта:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

- На ПК: `http://localhost:8000`
- С телефона в Wi-Fi сети: `http://<ваш-локальный-ip>:8000`
